| 2026-09-30 | **A2 — specification details, fixed before any S6 figure is computed** (written before `build_results_s6.py` exists; no S6 table has been generated). (a) **Tie-free at parent level and for ratios.** A query's rank-1 tied set is read from its top-100, as S5's `score_ties` does. Item tie-free = 1/\|set\| if the gold is in it, else 0 (S5). Parent tie-free = the share of the set in the gold's concept. Identity and modified queries are tie-broken independently, so a paired quantity is the product of expectations. R2's "wrong concept among losses" is Σ id_tf·(1 − parent_mod_tf) ÷ Σ id_tf·(1 − item_mod_tf); D is Σ item_tf ÷ Σ parent_tf; the gap is parent_tf − item_tf. Sets filling the whole top-100 are counted per cell. (b) **The no-number indicator** in M1 is 1 when the query holds no number and its gold holds at least one, so that it is zero at identity like the three deficits; the numeric-coverage deficit is 0 whenever the query holds no number. (c) **p against a non-zero null** (R3 at the PM threshold, R5 at the ratio threshold) is the two-sided bootstrap p of S4's `boot_p`, taken on draws minus the null. (d) **"PM undefined"**: the concept-clustered interval of Σ w β^{M0} (the pool's mean δ) contains 0; PM is then "—" and the test is read not supported, its p set to 1. R5's forced reading applies the same way. (e) **R4 pairing**: both arms' OLS fits are resampled with the same concept weights (the same bootstrap label), so the difference is paired. (f) **Clean subset**: the text detector (primary) flags; a flagged query is dropped from both sides of every contrast it enters. (g) **P8 in the models**: M0–M2 and PM are fitted with and without the four case-only queries. (h) **MixedLM**: REML, statsmodels' default optimiser; on a failure or a non-converged fit, refitted without the leaf component and marked. (i) **Floor** is re-checked tie-free on the treated leaves; if one of the seven named arms falls below 0.20 it is reported, and its tests stay registered as frozen | The frozen design defines tie-free Acc@1 at item level only (S5's), and leaves (b)–(i) as implementation choices; fixing them in the generator without a record would be choosing them after the code, which the auditor cannot check | None on any registered test's identity, population or direction. These fix how the frozen tests are computed, before any result exists |
