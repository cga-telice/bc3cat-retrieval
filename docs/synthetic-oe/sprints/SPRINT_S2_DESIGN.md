## Goal

At the end of S2 it is known whether the paper's central bet is alive: whether each of three
method families reads its own target back (identity ≥ 0.98), how far tuned BM25 falls under
the two L1 conditions H3 names, and whether rule-based structured matching overtakes it on
either of them. G1 is then read once, against thresholds fixed in `RESEARCH_PLAN.md` on
2026-09-14 — before any run existed — and not against thresholds chosen here.

## Design constraints

- **Metric for G1:** item-level Acc@1, dev. Parent-level reported beside it, always.
- **Identity is the paired reference.** Each L1 effect is the paired delta against the
  `texto` query of the *same gold leaves* (effect on the treated). Never compare raw Acc@1
  across `unit_conversion` and `num_to_text`: 13 vs 10 concepts, different leaves.
- **Cross-method comparisons are paired on identical query IDs.** Paired bootstrap, 10,000
  resamples, 95 % CI; plus a concept-clustered bootstrap as sensitivity, because each L1
  slice sits on ≤ 13 concepts and three families dominate each.
- **"Overtakes"** (question iii) means structured − BM25-params paired delta with a CI
  entirely above 0. A point-estimate lead is reported as such, not as inversion.
- **Thresholds are read on point estimates, CIs printed beside them.** If a CI straddles a
  threshold, the memo says so and G1 is recorded as *ambiguous on that arm*, not rounded.
- **D-010.** `bm25_unigram_params` builds query-side tokens from the record's parsed
  `parameters`, which a real query does not carry; item 1 of the report confirms or refutes
  this from the feature code. If confirmed it is labelled an oracle bound, and
  `bm25_unigram` is the deployable arm G1 is also read on. `structured_pipeline_rules`
  extracts from text only — realistic. No oracle-parent variant runs in S2.
- **Structured identity < 0.98 is not automatically a stop.** G1's stop branch guards the
  harness. For structured, a sub-threshold identity is first decomposed by stage (item 5);
  the stop applies only if BM25 or ColBERT identity is below 0.98, or if the structured
  shortfall is not explained by its stages.
- **`all_combined` is reported, not gated.** It always contains `template_paraphrase` and
  never `reorder`; its dose is quoted as `distinct_modification_count` (D-025).
- **No tuning.** No k1/b, preselect or extractor threshold is touched in S2 (D-012 is S3's).

## Exit criteria

1. 12 runs under `runs/OE/{texto,single_texto,stacked_texto}/…`, each with `run_meta.json`
   stamped at one clean commit (`code_dirty: false`).
2. Identity item Acc@1 for all four methods, each with a bootstrap CI, generated into
   `results/S2/`.
3. Paired deltas (condition − identity) per method for both L1 conditions, with CIs.
4. Paired structured − BM25-params and structured − BM25 deltas on both L1 conditions.
5. Structured stage table (item 5) and the 60-miss classification (item 6).
6. G1 read explicitly: one of *proceed* / *reframe* / *stop* / *ambiguous*, citing the
   stamped figures it rests on.
7. `pytest` green, including the ported-extractor test.

## Stopping criterion

Time-box **8 working days** from freeze. If the structured port (items 1–3) is not
producing runs by **day 4**, S2 closes on BM25 + ColBERT, G1 is read on (i)–(ii) only,
question (iii) is recorded as unanswered and moves to S5, and the deviation is amended here.

## Out of scope

Test split (S12). BM25 re-sweep and method scope (D-012, S3). Other single types, layer
pooling, mediation (S4, S6). Oracle and LLM structured variants (S5). Stacked stratification
(S7). Pantry-artefact exclusion analysis — the sidecar has not arrived (S6).

## Risks

| Risk | Handling |
|---|---|
| Port drags in more of the structured branch than listed | Stop at day 4 per stopping criterion |
| GPU / BGE-M3 server unavailable | ColBERT and E5 are the only GPU steps; start them first |
| BM25 L1 collapse is a feature artefact, not a rendering effect | Item 6 before G1 is read |
| ≤ 13 concepts per L1 slice make CIs optimistic | Clustered bootstrap sensitivity |
| Knowing the BM25 slice beforehand biases the reading | Thresholds taken verbatim from the plan; disclosed in the report |
