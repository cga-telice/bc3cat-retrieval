## Why subsetting is the harness's own metric

For all fifteen runs the mean of the per-query columns in `results_perquery.parquet` reproduces `metrics_dual.json` to within 5e-5, asserted by this generator before any filter is applied. Acc@1, Recall@k, RR and nDCG@10 are per-query values whose metric is their mean, so the mean over a subset is exactly the metric on that subset. If that assertion ever fails the generator stops, because subsetting would then be a second implementation of the metrics rather than the harness's own.
